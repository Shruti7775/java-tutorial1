Detective Investigation System

Team Project

This project is a Java-based console application that simulates a detective investigation for a missing examination question paper.

Features

* View all suspects
* Investigate a suspect
* Collect clues
* View collected clues
* Accuse a suspect
* Check whether the accusation is correct
* Maximum three accusation attempts
* Exit the investigation

Project Files

Suspect.java

Stores and manages information about the suspects.

ClueManager.java

Stores the five clues and keeps track of collected clues.

Investigation.java

Handles suspect searching, investigation, and accusation logic.

DetectiveGame.java

Contains the main method, menu, predefined choices, and integrates all classes.

Input

Scanner is not used because user-input handling is not required for this assignment.

The program uses predefined values to demonstrate the required operations.
